# AI Platform Historical Archive

This directory contains planning and status documents preserved from earlier AI Platform delivery phases.

These documents are useful for historical context, but they are not the current operating guide for contributors.

## Use Current Docs Instead

- For active onboarding, start with `../README.md`, `../FIRST_SETUP.md`, `../ENV_SETUP.md`, and `../TESTING.md`.
- For current deployment guidance, use `../DEPLOYMENT_AUTOMATION.md` and `../DEPLOYMENT_CHECKLIST.md`.
- For current service ownership and local runtime behavior, use `../SERVICE_BOUNDARIES.md` and `../SERVICE_PORTS.md`.

## Archived Planning Docs

- `DEPLOYMENT_ORDER.md` - retired Cloud Run deployment order retained for reference
- `NAVIGATION_GUIDE.md` - earlier navigation and integration notes retained for reference
- `SPRINT_DASHBOARD.md` - point-in-time platform scorecard and sprint dashboard
- `SPRINT_PLANNING.md` - earlier platform roadmap and delivery plan
- `SPRINT_1_ACTION_ITEMS.md` - day-by-day sprint task breakdown
- `KB_MVP_SPRINT_PLAN.md` - earlier knowledge-base MVP plan
- `TECHNICAL_DEBT.md` - historical debt register snapshot
- `RISK_REGISTER.md` - historical risk register snapshot

## Archive Notes

- Some documents refer to older rollout assumptions, including Cloud Run and pre-GKE operating models.
- If an archived document conflicts with live code, Make targets, or current READMEs, trust the active workspace docs.
