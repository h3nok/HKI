A proposal

Not a product. A contract any agentic platform can be built or audited against.

HKI 09 / 10
The runtime contract

Four properties any custody boundary must satisfy.

  • One active domain per operation signed before any retrieval, memory, or tool call begins.
  • Labels preserved through memory, cache, embeddings, async jobs, and telemetry — no surface drops them.
  • Cross-domain work uses scoped delegation and explicit release — never one mixed prompt or inferred global scope.
  • Every boundary testable through adversarial probes and verifiable release evidence across all runtime surfaces.
