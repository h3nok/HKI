Guaranteed Invariants

The Six Pillars of Hermetic Knowledge Isolation. Every downstream microservice, retrieval interface, database client, and tool pipeline must preserve these cryptographic bounds at run-time. They are verified end-to-end by @hki/conformance (28 cases, HKI-C01..C28).

  • 1 Single active domain active_domain is never null, "global", "*", or empty. Forces absolute domain specificity.
  • 2 Fail-closed Missing/invalid envelope = 401; unauthorized domain = 403. Security closed by default.
  • 3 Exact-match visibility Use same_domain() / sameHkiDomain() functions, never string comparisons or prefix matching.
  • 4 No body-scope override Body parameters (e.g. body.scope / body.domain) cannot replace or override the active_domain in the envelope.
  • 5 Explicit publication No implicit inheritance or cross-domain leaks. Cross-domain data requires signed publication.
  • 6 Admin plane separation Admin plane cross-domain reads are physically isolated and unreachable from runtime paths.

Install & Packages

Runtime packages for TypeScript and Python. The conformance kit integrates natively into local development workflows.

TypeScript runtime (@hki/runtime) 
$ npm install @hki/runtime

// Validate an HkiEnvelope
import { verifyEnvelope } from "@hki/runtime";
const result = verifyEnvelope(envelope);
Python runtime (hki-runtime) 
$ pip install hki-runtime[fastapi]

# Add FastAPI middleware for route isolation
from hki_runtime.fastapi import HkiMiddleware
app.add_middleware(HkiMiddleware)
Conformance kit (@hki/conformance) 
$ npm install @hki/conformance

# Run 28 conformance test suites
$ pnpm verify:hki-conformance
$ pnpm probe:smoke   # Launch HTTP network probes
Unified SDK (@hki/sdk) 
$ npm install @hki/sdk

// Mint narrowed envelopes at gateway edges
import { mintEnvelope } from "@hki/sdk/client";
const env = mintEnvelope({ activeDomain: "payments" });

Conformance Levels

Conformance levels are backed by reproducible cryptographic proof, not self-assessment. Run pnpm registry:build to compile a signed conformance registry.

L0
Documented

Domain surfaces mapped and cataloged. No active runtime boundaries claims are made.

L1
Labeled

All storage cells and runtime data carries verified, non-null domain headers.

L2
Routed

API requests carry exactly one signed HkiEnvelope during every asynchronous transaction.

L3
Enforced

Services reject transactions immediately if envelopes are missing, wildcard, or global.

L4
Tested

Automated negative test suites and active HTTP probes verify the boundary lines.

L5
Audited

Signed evidence and package binary signatures are independently reviewed by external systems.
